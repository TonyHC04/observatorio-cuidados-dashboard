# Dashboard – Observatorio de Autonomía y Cuidados

Cómo publicarlo (Streamlit Community Cloud):
1. Sube esta carpeta (app.py, requirements.txt, data/) a un repositorio de GitHub.
2. Entra a https://share.streamlit.io, inicia sesión con GitHub y elige "Create app".
3. Selecciona el repositorio, la rama y el archivo principal `app.py`. Deploy.
4. Copia el enlace publicado y ponlo en el reporte (Sección 4.1 y Anexo C).
5. Prueba el enlace en una ventana de incógnito.

Prueba local: pip install -r requirements.txt && streamlit run app.py
